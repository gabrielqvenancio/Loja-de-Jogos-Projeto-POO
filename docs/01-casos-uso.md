# Casos de uso

## I) Painel de Registro de Jogos
Temos como opções:
- Registrar um jogo;
- Listar os jogos registrados;
- Editar as informações de um jogo já registrado;
- Remover um jogo;

## II) Painel de Registro de Clientes
Temos como opções:
- Registrar um cliente;
- Listar os clientes cadastrados;
- Editar as informações de um cliente já cadastrado;
- Adicionar o saldo de um cliente;
- Remover um cliente;

## III) Painel de Transações
Temos como opções:
- Comprar um jogo;
- Vender um jogo;

Para uma boa efeituação da compra, há implementação dos sistema de: 
- Orçamentos de compra;
- Realizar a venda;

## IV) Painel de Trocas
Temos como opções:
- Realizar uma troca;

Para uma boa efeituação da troca, há implementação dos sistema de: 
- Orçamentos de troca;
- Realizar a troca;
