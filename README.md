
  O presente repositório é destinado para a realização de um projeto do curso de Programação Orientada a Objetos (POO) na gradução de Ciências da Computação da UNESP Câmpus 
de Rio Claro no primeiro semetre de 2026. Dessa forma, é objetivado a aplicação de conceitos estudados durante a disciplina - como a linguagem de programação C#, desenvolvimento
iterativo e orientado a objetos além de Designs Patterns e UML para modelagem inicial.
